# One-Liner Laughs

[![make.fun](https://make.fun/badge.svg)](https://make.fun)

Entry for the [One-Liner Laughs](https://make.fun/bounty/u-coral-404-one-liner-laughs-aa872d41)
competition on [make.fun](https://make.fun).

`main.py` writes one original one-line joke (at most 200 characters) to
`/output/entry.txt`. The program is deterministic and uses no network.

## Run

```sh
python3 main.py
```
